# Кто конкурент Drinkit? Телефонная версия

Страница для участников семинара «Маркетинговые стратегии», ГДЗ 1 «Границы рынка».
Участник выбирает карточки конкурентов новой точки Drinkit и получает номер команды: А, Б, В или Г.

Правило: 2 и больше карточки из широкой группы (Б, В или Г) ведут в эту команду; если таких групп несколько, побеждает большая доля выбранных карточек группы; иначе команда А.

Учебный проект команды «10 из 10». Не является сайтом Drinkit или Dodo Brands.
